Async / Await in JavaScript

What is Async/Await?

Async/Await is a modern way of handling asynchronous operations in JavaScript. It is built on top of Promises and provides a cleaner, more readable syntax for working with asynchronous code.

Why Was Async/Await Introduced?

Before Async/Await, asynchronous operations were handled using Callbacks and Promises.

While Promises solved Callback Hell, long Promise chains can still become difficult to read and maintain. 

Callbacks
     ↓
Promises
     ↓
Async / Await

What is async?

The async keyword is used before a function to make it return a Promise automatically. 

async function greet() {
    return "Hello";
}

Even though a string is returned, JavaScript wraps it inside a Promise. 

Promise { "Hello" }

What is await?

The await keyword pauses the execution of an async function until the Promise is resolved or rejected. 

const data = await fetchData();

JavaScript waits for the Promise to complete and then stores the resolved value inside the variable.

Important Rule

async → Makes a function return a Promise

await → Waits for a Promise to resolve

The await keyword can only be used inside an async function.

Execution Flow

Call Async Function
        ↓
Promise Created
        ↓
Await Encountered
        ↓
Wait For Promise Result
        ↓
Promise Resolved
        ↓
Continue Execution

Promise vs Async/Await

Using Promises

fetchUser()
    .then(user => {
        console.log(user);
    })
    .catch(error => {
        console.log(error);
    });

Using Async/Await

try {
    const user = await fetchUser();
    console.log(user);
}
catch(error) {
    console.log(error);
}

Async/Await is easier to read because it looks like synchronous code.

Real-Time Example: User Login

User Clicks Login
        ↓
Server Verification
        ↓
Login Successful
        ↓
Dashboard Opens

The application waits for the server response before proceeding.

Real-Time Example: Food Delivery

Place Order
      ↓
Prepare Food
      ↓
Deliver Food
      ↓
Order Completed

Each step waits for the previous step to complete.

Real-Time Example: API Call

Send Request
      ↓
Server Processing
      ↓
Response Received
      ↓
Display Data

Most modern API calls in React and Node.js applications use Async/Await.

Error Handling

Async/Await uses try/catch blocks to handle errors. 

try {

    const data = await fetchData();

    console.log(data);

}
catch(error) {

    console.log(error);

}

Advantages of Async/Await

  • Cleaner syntax.
  • Easy to read and maintain.
  • Avoids long Promise chains.
  • Better error handling with try/catch.
  • Makes asynchronous code look synchronous.

Disadvantages of Async/Await

  • Can make independent operations run sequentially if used incorrectly.
  • Requires understanding of Promises.

Where is Async/Await Used?

  • API Calls (fetch, axios)
  • Database Queries
  • Authentication & Authorization
  • File Uploads
  • Payment Processing
  • React Applications
  • Node.js Applications
  • Cloud Services

Async/Await and Event Loop

Async/Await is built on top of Promises.

Promise resolutions are placed in the Microtask Queue and are processed by the Event Loop before Macrotasks such as setTimeout. 

Call Stack Empty
       ↓
Microtask Queue
       ↓
Macrotask Queue

Frequently Asked Interview Questions

1. Can await be used without async?

No. Await can only be used inside an async function (except top-level await in ES modules).

2. Does async make code synchronous?

No. It only makes asynchronous code look synchronous.

3. What does an async function return?

An async function always returns a Promise.

4. Is Async/Await better than Promises?

Async/Await is built on Promises and provides a cleaner syntax. Internally, Promises are still being used.

Interview Definition

Async/Await is a Promise-based feature in JavaScript that allows asynchronous code to be written in a synchronous-looking manner, improving readability, maintainability, and error handling.
