Callbacks in JavaScript

What is a Callback?

A callback is a function that is passed as an argument to another function and is executed after a specific task is completed.

Why Do We Need Callbacks?

Callbacks help us execute code after an operation finishes. They are commonly used for asynchronous tasks such as:

  • API Calls
  • File Downloads
  • Database Operations
  • User Events (Click, Scroll, Input)
  • Timers (setTimeout, setInterval)

Callback Syntax

function mainFunction(callback) {
    callback();
}

The callback function is passed to another function and executed later.

Real-Time Example: Resume Download

downloadResume(openResume);

The resume is downloaded first. Once the download is complete, the callback function opens the resume.

Execution Flow

Download Resume
        ↓
Download Complete
        ↓
Execute Callback
        ↓
Open Resume

Another Real-Time Example

User Registration System: 

Register User
        ↓
Registration Complete
        ↓
Send Welcome Email

The welcome email should only be sent after the user is successfully registered. A callback helps maintain this sequence.

Callbacks and Asynchronous JavaScript

Callbacks are widely used in asynchronous operations. JavaScript continues executing other code while waiting for tasks such as API requests or timers to complete.

Advantages of Callbacks

  • Handle asynchronous operations.
  • Execute code after a task completes.
  • Improve code flexibility and reusability.
  • Allow custom behavior to be passed into functions.

Disadvantages of Callbacks

  • Can lead to deeply nested code.
  • Harder to read and maintain.
  • May result in Callback Hell.

What is Callback Hell?

Callback Hell occurs when multiple callbacks are nested inside one another, making the code difficult to read and maintain. 

Task 1
   ↓
Task 2
   ↓
Task 3
   ↓
Task 4

To solve Callback Hell, JavaScript introduced Promises and later Async/Await.

Interview Definition

A callback is a function passed as an argument to another function and executed after a particular task or operation has been completed.
