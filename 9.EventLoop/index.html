JavaScript Event Loop

What is the Event Loop?

The Event Loop is a mechanism that continuously checks whether the Call Stack is empty and moves tasks from the queues to the Call Stack for execution.

JavaScript Runtime Components

1. Call Stack

The Call Stack executes JavaScript code one function at a time.

2. Web APIs

Browser-provided features such as:

  • setTimeout()
  • setInterval()
  • Fetch API
  • DOM Events

3. Callback Queue (Macrotask Queue)

Stores callbacks from setTimeout, setInterval, and DOM events waiting to be executed.

4. Microtask Queue

Stores high-priority tasks such as:

  • Promise.then()
  • Promise.catch()
  • queueMicrotask()

5. Event Loop

The Event Loop checks whether the Call Stack is empty. If it is, it executes all Microtasks first and then executes Macrotasks.

Execution Order

  1. Run synchronous code.
  2. Execute all Microtasks.
  3. Execute one Macrotask.
  4. Repeat the process.

Important Rule

Microtasks always have higher priority than Macrotasks. 

Call Stack Empty
        ↓
Run All Microtasks
        ↓
Run One Macrotask
        ↓
