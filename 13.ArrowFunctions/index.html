Arrow Functions in JavaScript

What is an Arrow Function?

Arrow Functions were introduced in ES6 (ECMAScript 2015) as a shorter and cleaner way to write functions.

They use the => syntax and are widely used in modern JavaScript, React, Node.js, and API handling.

Why Were Arrow Functions Introduced?

  • Reduce boilerplate code.
  • Improve readability.
  • Make callbacks easier to write.
  • Provide lexical this binding.
  • Work well with Promises and Array Methods.

Traditional Function vs Arrow Function

Traditional Function

function greet(name) {
    return "Hello " + name;
}

Arrow Function

const greet = (name) => {
    return "Hello " + name;
};

Arrow Function Syntax

No Parameters

const greet = () => {
    console.log("Hello");
};

One Parameter

const greet = name => {
    console.log(name);
};

Multiple Parameters

const add = (a, b) => {
    return a + b;
};

Implicit Return

const add = (a, b) => a + b;

When the function contains only one expression, the return keyword can be omitted.

Where Are Arrow Functions Used?

  • Callbacks
  • Promises
  • Async/Await
  • Array Methods
  • Event Handlers
  • React Components
  • API Calls

Real-Time Example: API Call

fetch(url)
    .then(response => response.json())
    .then(data => console.log(data))
    .catch(error => console.log(error));

Arrow Functions make Promise chains shorter and easier to read.

Real-Time Example: Array Methods

const prices = [100, 200, 300];

const discountedPrices =
    prices.map(price => price - 10);

Arrow Functions are commonly used with map(), filter(), reduce(), find(), and forEach().

Real-Time Example: Event Handling

button.addEventListener("click", () => {
    console.log("Button Clicked");
});

The Most Important Interview Topic: this Keyword

Arrow Functions do not have their own this.

They inherit this from the surrounding scope (lexical scope).

Traditional Function

const person = {

    name: "Praveen",

    greet: function() {
        console.log(this.name);
    }

};

person.greet();

Output:

Praveen

Arrow Function

const person = {

    name: "Praveen",

    greet: () => {
        console.log(this.name);
    }

};

person.greet();

Output:

undefined

Because Arrow Functions do not create their own this context.

Lexical this

Lexical this means the Arrow Function uses the this value from the outer scope where it was created.

Real-Time Example

function Counter() {

    this.count = 0;

    setTimeout(() => {
        console.log(this.count);
    }, 1000);

}

new Counter();

Arrow Functions solve many this-related issues inside callbacks.

Can Arrow Functions Be Constructors?

No.

const Person = (name) => {
    this.name = name;
};

new Person("Praveen");

This throws an error because Arrow Functions cannot be used with new.

Advantages of Arrow Functions

  • Shorter syntax.
  • Cleaner code.
  • Lexical this binding.
  • Excellent for callbacks.
  • Widely used in React and modern JavaScript.

Disadvantages of Arrow Functions

  • No own this.
  • Cannot be used as constructors.
  • Not suitable for object methods that rely on this.

When Should You Use Arrow Functions?

  • Callbacks
  • Promise Handling
  • Async/Await Functions
  • Array Methods
  • Event Listeners

When Should You Avoid Arrow Functions?

  • Object Methods using this.
  • Constructor Functions.
  • Prototype Methods.
