JavaScript Closures

What is a Closure?

A Closure is a function that remembers and has access to variables from its outer (lexical) scope even after the outer function has finished executing.

Why Do Closures Exist?

Normally, local variables inside a function are destroyed when the function execution completes. Closures allow inner functions to retain access to those variables even after the outer function has returned.

How Closures Work

When an inner function is returned or passed elsewhere, JavaScript keeps a reference to the variables in the outer scope. This preserved relationship between the function and its lexical environment is called a Closure.

Closure Components

  • Outer Function
  • Inner Function
  • Lexical Scope
  • Preserved Variables

Lexical Scope and Closures

Closures are possible because JavaScript uses lexical scoping. An inner function can access variables defined in its parent function.

Real World Uses of Closures

  • Data Privacy
  • Encapsulation
  • Counters
  • Module Pattern
  • Event Handlers
  • Callbacks
  • Timers
  • Memoization

Advantages of Closures

  • Data hiding
  • Private variables
  • State preservation
  • Better code organization
  • Supports functional programming

Disadvantages of Closures

  • Can consume additional memory.
  • May cause memory leaks if not used carefully.
  • Can make debugging more difficult.
