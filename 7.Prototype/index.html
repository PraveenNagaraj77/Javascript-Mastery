Prototypes

JavaScript Prototypes

What is a Prototype?

A Prototype is an object that allows other objects to inherit properties and methods.

JavaScript uses prototypes to achieve inheritance and method sharing.

Why Do We Need Prototypes?

Imagine creating 1000 user objects.

If every object contains its own copy of the same function, memory is wasted.

Prototypes allow all objects to share a single copy of a method.

Without Prototype

function User(name) {
    this.name = name;

    this.greet = function() {
        console.log("Hello");
    };
}

Every object gets its own copy of greet().

More memory is consumed.

Using Prototype

function User(name) {
    this.name = name;
}

User.prototype.greet = function() {
    console.log("Hello");
};

Now every object shares the same greet() function.

Memory efficient and faster.

Prototype Lookup

When JavaScript cannot find a property on an object, it looks inside the object's prototype.

This process continues until the property is found or the end of the prototype chain is reached.

Prototype Chain

arr
 ↓
Array.prototype
 ↓
Object.prototype
 ↓
null

This chain of linked prototype objects is called the Prototype Chain.

Real World Example

Employee System

function Employee(name) {
    this.name = name;
}

Employee.prototype.login = function() {
    console.log(this.name + " logged in");
};

Employee.prototype.logout = function() {
    console.log(this.name + " logged out");
};

Thousands of employees can share the same login() and logout() methods.

Only one copy exists in memory.

prototype vs __proto__

prototype

Exists on constructor functions. 

User.prototype

Used to add shared methods and properties.

__proto__

Exists on objects. 

user1.__proto__

Points to the constructor's prototype object.

Important Interview Question

Why do we use Prototypes?

Prototypes allow objects to share methods and properties. This reduces memory usage and improves performance because functions are stored once and reused by all instances.

Key Points to Remember

  • JavaScript uses Prototype-based inheritance.
  • Every object has a prototype.
  • Functions have a prototype property.
  • Objects have a __proto__ reference.
  • Methods can be shared through prototypes.
  • Prototype chains enable inheritance.
