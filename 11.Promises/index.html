Promises in JavaScript

What is a Promise?

A Promise is an object that represents the eventual success or failure of an asynchronous operation.

A Promise acts as a placeholder for a value that will be available in the future.

Why Do We Need Promises?

Before Promises, JavaScript relied heavily on callbacks for handling asynchronous operations.

Multiple nested callbacks often resulted in Callback Hell, making code difficult to read and maintain. 

Task 1
  ↓
Task 2
  ↓
Task 3
  ↓
Task 4

Promises provide a cleaner and more readable way to manage asynchronous tasks.

Promise States

  • Pending - Initial state, operation is in progress.
  • Fulfilled (Resolved) - Operation completed successfully.
  • Rejected - Operation failed.
Pending
   ↓
Resolved (Success)

OR

Pending
   ↓
Rejected (Failure)

Creating a Promise

const promise = new Promise((resolve, reject) => {

    let success = true;

    if(success){
        resolve("Operation Successful");
    }else{
        reject("Operation Failed");
    }

});

Consuming a Promise

promise
    .then((result) => {
        console.log(result);
    })
    .catch((error) => {
        console.log(error);
    });

Promise Methods

1. then()

Executes when the Promise is resolved successfully. 

promise.then((result) => {
    console.log(result);
});

2. catch()

Executes when the Promise is rejected. 

promise.catch((error) => {
    console.log(error);
});

3. finally()

Executes regardless of success or failure. 

promise.finally(() => {
    console.log("Operation Completed");
});

Real-Time Example: Food Delivery App

Order Placed
      ↓
Food Being Prepared
      ↓
Food Delivered

While the food is being prepared, the Promise remains in the Pending state.

Once delivered, the Promise is Resolved.

If the restaurant cancels the order, the Promise is Rejected.

Real-Time Example: User Login

User Clicks Login
        ↓
Server Verification
        ↓
Login Successful

The application waits for the server response before proceeding. Promises help manage this asynchronous process.

Real-Time Example: API Calls

Request Sent
      ↓
Waiting For Response
      ↓

      ↓
Display Data

Modern APIs such as fetch() return Promises. 

fetch("users")
    .then(response => response.json())
    .then(data => console.log(data));

Promise Chaining

Multiple asynchronous operations can be executed in sequence using Promise chaining. 

placeOrder()
    .then(() => prepareFood())
    .then(() => deliverFood())
    .then(() => {
        console.log("Order Completed");
    });

Advantages of Promises

  • Avoid Callback Hell.
  • Improve code readability.
  • Better error handling.
  • Easier chaining of asynchronous operations.
  • Foundation for Async/Await.

Where Are Promises Used?

  • API Calls
  • Database Queries
  • Authentication
  • File Uploads
  • Payment Processing
  • React Applications
  • Node.js Applications

Promises and the Event Loop

Promise callbacks are placed in the Microtask Queue.

Microtasks are executed before Macrotasks such as setTimeout. 

Call Stack Empty
       ↓
Run All Microtasks
       ↓
Run One Macrotask
       ↓
Repeat
