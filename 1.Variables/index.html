JavaScript Variables

What is a Variable?

A variable is a container used to store data values in JavaScript. Variables allow us to store information and reuse it throughout the program.

Why Do We Need Variables?

Variables help us store and manage data efficiently. Instead of hardcoding values, we can store them in variables and use them whenever needed.

Types of Variable Declarations

1. var

The var keyword was used before ES6. It is function-scoped and can be redeclared and reassigned. 

var name = "Praveen";
var name = "Kumar"; // Allowed
console.log(name);

2. let

The let keyword was introduced in ES6. It is block-scoped and can be reassigned but cannot be redeclared in the same scope. 

let age = 25;
age = 26; // Allowed

// let age = 30; ❌ Error

3. const

The const keyword is also block-scoped. Once assigned, its value cannot be reassigned. 

const country = "India";

// country = "USA"; ❌ Error

Difference Between var, let, and const

Feature var let const
Scope Function Block Block
Redeclare Yes No No
Reassign Yes Yes No
Hoisting Yes Yes (TDZ) Yes (TDZ)

Variable Naming Rules

  • Must start with a letter, underscore (_) or dollar sign ($).
  • Cannot start with a number.
  • Cannot use reserved keywords.
  • JavaScript is case-sensitive.

Valid Variable Names

let firstName;
let _age;
let $salary;
let user123;

Invalid Variable Names

let 123name;    // ❌
let first-name; // ❌
let class;      // ❌

Data Types Stored in Variables

let name = "Praveen";     // String
let age = 28;             // Number
let isEmployee = true;    // Boolean
let salary = null;        // Null
let address;             // Undefined

Best Practices

  • Use const by default.
  • Use let when value needs to change.
  • Avoid var in modern JavaScript.
  • Use meaningful variable names.
