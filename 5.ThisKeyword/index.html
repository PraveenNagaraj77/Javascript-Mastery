JavaScript - this Keyword

What is this?

this is a special keyword in JavaScript that refers to the object that is currently executing the function.

The value of this is determined by how a function is called, not where it is defined.

Rule 1: Global Context

In the browser, this refers to the global window object. 

console.log(this);

Output: Window

Rule 2: Inside an Object Method

const person = {
    name: "Praveen",

    greet() {
        console.log(this.name);
    }
};

person.greet();

Here, this refers to the person object because the method is called using person.greet().

Output: Praveen

Rule 3: Normal Function

function greet() {
    console.log(this);
}

greet();

In non-strict mode, this refers to the global window object.

Output: Window

Rule 4: Arrow Functions

const person = {
    name: "Praveen",

    greet() {
        const inner = () => {
            console.log(this.name);
        };

        inner();
    }
};

person.greet();

Arrow functions do not create their own this. They inherit this from the surrounding scope.

Output: Praveen

Rule 5: Constructor Functions

function Person(name) {
    this.name = name;
}

const user = new Person("Praveen");

When a function is called using the new keyword, this refers to the newly created object.

call(), apply(), bind()

call()

greet.call(person);

call() invokes a function immediately and sets the value of this.

apply()

greet.apply(person, ["Chennai"]);

apply() works like call(), but arguments are passed as an array.

bind()

const newFunc = greet.bind(person);

bind() does not execute immediately. It returns a new function with this permanently bound to the specified object.

Interview Shortcut

Whenever you see this, ask:

  1. Who called the function?
  2. Is it a normal function?
  3. Is it an object method?
  4. Is it an arrow function?
  5. Was it called using new?

Answering these questions will help you determine the value of this in almost every interview question.
