JavaScript - Call, Apply & Bind

Why do we need Call, Apply and Bind?

In JavaScript, the value of this depends on how a function is called.

Sometimes we want to manually control what this refers to.

JavaScript provides three methods:

  • call()
  • apply()
  • bind()

These methods allow a function to borrow properties and methods from another object. This concept is called Function Borrowing.

Function Borrowing

Instead of creating the same function for multiple objects, we create one function and reuse it for different objects.

Benefits:

  • Less code duplication
  • Reusable functions
  • Better maintainability

call()

call() invokes a function immediately and allows us to specify the value of this.

Syntax

functionName.call(object, arg1, arg2);

Example

printFullName.call(
    name2,
    "Bengaluru",
    "Kannada"
);

Here:

  • this = name2
  • hometown = Bengaluru
  • language = Kannada

apply()

apply() works exactly like call().

The only difference is that arguments are passed as an array.

Syntax

functionName.apply(object, [arg1, arg2]);

Example

printFullName.apply(
    name,
    ["Chennai", "English"]
);

bind()

bind() does not execute the function immediately.

Instead, it returns a new function with a permanently attached value of this.

Syntax

const newFunction =
    functionName.bind(object);

Example

let printMyName =
    printFullName.bind(
        name2,
        "Mumbai",
        "Maharastra"
    );

At this point, nothing is executed.

Execution happens only when: 

printMyName();

Real-Time Uses

call()

  • Function borrowing
  • Reusable utility functions
  • Sharing methods across objects

apply()

  • When arguments already exist in an array
  • Dynamic function execution
  • Processing API response arrays

bind()

  • Event handlers
  • setTimeout callbacks
  • React components
  • Preserving this context

Interview Differences

Feature call() apply() bind()
Executes Immediately Yes Yes No
Returns Function No No Yes
Arguments Separate Array Separate

Interview One-Liner

call() → Execute now with a specific this.

apply() → Execute now with a specific this and array arguments.

bind() → Execute later with a specific this.
